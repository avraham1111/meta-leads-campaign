# סוכן קמפיינים לידים במטא

סקיל ל-Claude שהופך אותו למנהל הקמפיינים שלך בפייסבוק ובאינסטגרם — שואל את
השאלות הנכונות, מתקין את המעקב באתר, בונה את הקמפיין, קורא את הנתונים וממליץ
מה לשנות.

**📄 [עמוד ההוראות המלא](https://avraham1111.github.io/meta-leads-campaign/)**
· **⬇️ [הורדת הסקיל (ZIP)](https://avraham1111.github.io/meta-leads-campaign/meta-leads-campaign.zip)**

---

## התקנה

### אם אתה עובד ב-Claude Code

הכי מהיר — תדביק לקלוד שלך את זה:

```
תתקין לי את הסקיל מהריפו הזה:
https://github.com/avraham1111/meta-leads-campaign
```

הוא ימשוך את הקובץ ויתקין אותו בעצמו.

### אם אתה עובד באפליקציית Claude או בדפדפן

1. [להוריד את ה-ZIP](https://avraham1111.github.io/meta-leads-campaign/meta-leads-campaign.zip)
2. **Settings** ← **Capabilities** ← להפעיל **Create and edit files**
3. **Settings** ← **Customize** ← **Skills** ← **+** ← **Create skill** ←
   **Upload a skill**
4. להעלות את ה-ZIP כמו שהוא, בלי לפתוח אותו

### החיבור לחשבון המודעות — בלי זה הוא לא יוכל לבנות כלום

**Settings** ← **Connectors** ← **Add custom connector** (לא נמצא בחיפוש, צריך
להוסיף ידנית), שם `Meta Ads`, וכתובת:

```
https://mcp.facebook.com/ads
```

ההתחברות היא דרך **פייסבוק** (לא גוגל). צריך לאשר הרשאת ניהול
(`ads_management`) ולא רק קריאה — אחרת הוא יוכל להראות נתונים אבל לא לבנות.

## איך מתחילים

שיחה חדשה, ולכתוב:

> אני רוצה להרים קמפיין לידים בפייסבוק

אם ההתקנה הצליחה הוא יתחיל לשאול שאלות קצרות עם אפשרויות לבחירה, ולא ייתן
תשובה כללית.

---

## מה הוא לא יעשה בלי אישור שלך

- לא יקבע תקציב לבד — ימליץ, ואתה מאשר את הסכום המדויק
- לא יפעיל, יעצור או ישנה תקציב בלי "כן" מפורש ממך
- לא ימציא נתונים — כל מספר בא ממטא, מהאתר שלך או ממך
- לא יעלה קמפיין בלי תקציב מוגדר ובלי תאריך סיום או תאריך בדיקה
- לא יגע באמצעי התשלום. כרטיס אשראי זה תמיד אתה, בעצמך
